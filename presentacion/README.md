# Presentación web — Sistema Olimpiadas Perú

Presentación navegable basada en el informe principal del proyecto.

## Estructura

```text
presentacion/
├── index.html                 # Entrada de la presentación
└── assets/
    ├── css/presentation.css   # Diseño responsivo
    └── js/
        ├── slides.js          # Contenido de las diapositivas
        ├── renderer.js        # Renderizado de una diapositiva
        └── main.js            # Navegación y controles
```

## Uso

Abrir `index.html` en cualquier navegador moderno. No requiere instalación ni
servidor. Navegación disponible con los botones, las flechas del teclado,
Espacio, Page Up/Page Down, Home y End.

Para una presentación más cómoda se recomienda usar pantalla completa del
navegador (`F11`).
